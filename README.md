# ИВРИКА: первые шаги в чтении на иврите

[Борд с 20 анимированными слайдами](https://ivrikacomments.github.io/yt-feed/)

[Финальный борд с готовым видео](https://ivrikacomments.github.io/yt-feed/watch.html)

[Видео на YouTube](https://youtu.be/8Gd6u78qSbE)

## Материалы

- index.html: учебные слайды и анимированный макет, версия 6.
- watch.html: готовое видео с YouTube и ссылка на слайды.
- video-config.js: адрес видео YouTube.
- materials.zip: редактируемые материалы бордов.
- assets/ и slides/: локальные шрифты, изображения и библиотека анимации.
- cover.jpg: обложка с фотографией и флагом.

Сайт статический, без сборки и серверных зависимостей. GitHub Pages публикует main, корень репозитория. .nojekyll отключает обработку Jekyll.

Исходные видеозаписи, большой MP4, WAV, промежуточные рендеры и монтажные инструменты не входят в репозиторий.
